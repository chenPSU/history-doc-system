# ระบบผลิตสารคดีประวัติศาสตร์ (ช่องอังกฤษ + ช่องไทย)

โปรเจกต์ตั้งต้นสำหรับให้ Claude Code สร้างระบบผลิตคลิปต่อ ตามแผนที่วางไว้ใน 4 เอกสาร: วิเคราะห์ตลาด, Roadmap, Style Guide และผลทดลองการเล่า 5 รอบ

## เริ่มใช้งาน

1. แตกไฟล์ zip แล้วเปิดโฟลเดอร์ `history-doc-system` ใน Terminal
2. พิมพ์ `claude` เพื่อเปิด Claude Code
3. พิมพ์คำสั่งแรก:

```
อ่าน CLAUDE.md และ TASKS.md แล้วเริ่ม P0.1: ถามผมเรื่องที่ยังไม่ได้ตัดสินใจใน docs/decisions.md ทีละข้อ
```

จากนั้นใช้ `/next-task` เพื่อทำงานข้อถัดไปทีละข้อ

## คำสั่งลัดใน Claude Code

| คำสั่ง | ทำอะไร |
|---|---|
| `/next-task` | ทำงานข้อถัดไปใน TASKS.md แล้วติ๊กเมื่อผ่านเกณฑ์ |
| `/episode 2026-12-07-en-korea` | เขียน fact sheet → บท → ให้คะแนน → shot list ของตอนนั้น |
| `/score <ไฟล์บท>` | ให้คะแนนบท 36 ข้อ แล้วบอกว่าต้องแก้บรรทัดไหน |

## มีอะไรในโปรเจกต์

| ไฟล์/โฟลเดอร์ | คืออะไร |
|---|---|
| `CLAUDE.md` | คู่มือที่ Claude Code อ่านทุกครั้ง: เป้าหมาย กฎ ด่านตรวจคุณภาพ วันสำคัญ |
| `TASKS.md` | แผนสร้างระบบ 6 เฟส (บท → เสียง → ภาพ → ตัดต่อ → แพ็กเกจ → วัดผล) พร้อมเกณฑ์ผ่าน |
| `docs/` | Style Guide, Roadmap, ผลทดลอง 5 รอบ, สรุปตลาด, ตารางการตัดสินใจ |
| `.claude/skills/history-doc-episode/` | วิธีเขียนแพ็กเกจตอน (อัปเดตกฎจากการทดลองแล้ว) |
| `tools/score.py` | ตัวให้คะแนนบท 36 ข้อ |
| `tools/new_episode.py` | สร้างโฟลเดอร์ตอนจากแม่แบบ |
| `tools/check_episode.py` | ด่านคะแนนบท เขียนผลลง score.json |
| `tools/upload.py`, `pipeline/youtube_upload.py` | อัปโหลดขึ้น YouTube อัตโนมัติ (ตั้งค่าตาม `docs/upload-setup.md`) |
| `config/upload_policy.yaml` | นโยบายอัปโหลดที่คุณคุม: โหมด, เวลาเผยแพร่, ต้องอนุมัติหรือไม่ |
| `data/episodes.csv` | 16 ตอนเฟส 1 พร้อม hook และภาพหลัก (อังกฤษ + ไทย) |
| `episodes/2026-12-14-en-constantinople/` | ตอนแรกที่ทดสอบแล้ว (บท 6.6 นาที ผ่านด่านคะแนน) |
| `templates/episode/` | แม่แบบโฟลเดอร์ตอน |

## หลักที่ระบบนี้ยึด

- ช่องอังกฤษเป็นช่องหลัก ช่องไทยใช้งานค้นคว้าและภาพชุดเดียวกัน บวกตอนเฉพาะไทย
- เป้าแรก: ตอน Constantinople ต้องผ่านระบบครบทุกขั้นภายใน **14 ธ.ค. 2026**
- เส้นตาย YPP: **31 ม.ค. 2027** (หลังจากนั้นเกณฑ์เวลาดูเพิ่มเป็น 8,000 ชั่วโมง)
- ระบบอัปโหลดเองได้ตาม `config/upload_policy.yaml` ซึ่งคุณเป็นคนคุม ทุกตอนต้องผ่านด่านคะแนน, preflight, ลิขสิทธิ์ภาพ และเช็กว่าขึ้นถูกช่องก่อน
- **ต้องผ่านการตรวจโปรเจกต์ API ของ Google ก่อน** วิดีโอที่อัปผ่าน API ถึงจะเป็นสาธารณะได้ ระหว่างรอให้อัปเองใน Studio (ดู `docs/upload-setup.md`)
- Claude Code จะไม่ใช้บริการที่เสียเงินโดยไม่ถามคุณก่อน
